# NearbyPass

一个 macOS 菜单栏小程序：用蓝牙信号判断你在不在电脑前，然后替你解锁或锁屏。

三个功能：

- 人在，系统要你输密码（改设置、装软件那种弹窗）时，自动填进去
- 人回来，电脑锁着，自动解锁
- 人走了，自动锁屏

它不碰系统认证逻辑，不装认证插件，也不用 root。做的只是：看蓝牙信号、看有没有弹窗、往密码框里写字、模拟一次锁屏快捷键。

## 安装

去 [Releases](https://github.com/ThursdayV50/NearbyPass/releases) 下载 dmg，打开后把 `NearbyPass` 拖到旁边的「应用程序」文件夹。

没做 Apple 公证，第一次打开会被 Gatekeeper 拦。右键点图标 → 打开，确认一次就行。

第一次运行会走一遍教程。之后有新版本会在 App 里提示，点一下就自动下载安装重启，不用自己替换文件。前提是 App 放在「应用程序」文件夹里。

也可以自己编译，见下面。

## 用起来要三步

**1. 给辅助功能权限**

系统设置 → 隐私与安全性 → 辅助功能 → 加上 NearbyPass。

没这个权限它什么都干不了，填密码和锁屏全靠它。菜单栏点开有「权限自检」，可以直接跳过去。

**2. 勾选你的设备**

菜单栏 → 设置，列表里找到你的手机或手环，勾上左边的框。前面的 ★ 是「解锁主设备」，自动解锁只认这一台。

设备第一次出现时名字可能是 `NGMeCvX2Lpr6xumgxKmaOTmRY` 这种随机串（安卓手机常见）。点名字右边的「改」自己起个名，或者勾选时会自动弹出来让你改。名字会记住。

**3. 设置登录密码**

点「设置密码」，输你的开机密码。它存在 `~/Library/Application Support/NearbyPass/secret.bin`，权限 600，只有你自己能读。

存文件而不是钥匙串，是因为钥匙串读取会弹授权框——锁屏状态下没人能点，自动解锁就死那儿了。

三步做完，菜单栏图标会显示当前信号强度，比如 `● -58`。

## 两个阈值

设置里有两个滑块：

- **解锁强度**：信号强到这个值以上，认为你在
- **锁屏强度**：信号弱到这个值以下，认为你走了

中间是缓冲区，防止信号在某个值附近抖动导致反复锁屏解锁。

默认 -70 / -85。手机放桌上一般是 -50 到 -70，揣兜里走出去几步就掉到 -85 以下。要是发现人还在就被锁了，把解锁强度调低一点（往左拖）。

拖滑块的时候下面有一行实时提示，会告诉你「此刻锁屏 → 会自动解锁」，不用瞎猜。

## 怎么实现的

**判断在场**：CoreBluetooth 扫描 BLE 广播，对指定设备做 RSSI 指数平滑，配合双阈值和迟滞带。手机广播间隔本身就有 10 到 20 秒，所以判定窗口给得比较宽。

**找密码弹窗**：`CGWindowListCopyWindowInfo` 轮询桌面窗口，认出系统认证弹窗（`SecurityAgent`、`coreautha`，还有挂在系统设置上的 sheet）。拿到之后通过 Accessibility 直接往密码框写值，再按「好」或「修改设置」提交。

**自动解锁**：锁屏后 `loginwindow` 的密码框是标准 AX 元素，同样是 AX 写值 + 点 `login` 按钮。如果屏保挡在前面，先合成一次 Shift 把它退掉。

**自动锁屏**：模拟 `Ctrl+Cmd+Q`。

**该不该解锁**：这是唯一有点绕的地方。你按 Ctrl+Cmd+Q 主动锁屏、手机就放桌上，如果无脑解开，锁屏功能就白做了。所以每次锁屏都先判断原因：

- NearbyPass 自己锁的 → 人走了，会解锁
- 90 秒以上没键鼠输入（屏保、显示器休眠）→ 算空闲锁屏，会解锁
- 你亲手锁的且设备在附近 → 人还在，不解锁，直到设备先离开再回来

**密码安全**：只在系统认证弹窗出现、设备在附近、且你点了「允许」之后才写。自动解锁不弹确认，所以门槛卡得紧一点：信号持续达标 5 秒、每次锁屏只试一次、密码错一次就停手（macOS 连续输错会锁账户）。日志里密码一律替换成 `***`。

## 自己编译

```bash
git clone https://github.com/ThursdayV50/NearbyPass.git
cd NearbyPass
./build.sh --run
```

需要 Xcode 命令行工具。`build.sh` 调 `swiftc` 直接编译，然后手工组装 `.app`、签名。

仓库里没有签名证书，默认用 ad-hoc 签名。这样每次重新编译辅助功能授权都要重新勾一次，因为 ad-hoc 签名的要求里绑着二进制哈希。嫌烦就自己生成一套固定证书。

图标是 `Resources/make-icon.swift` 用 CoreGraphics 画的，改颜色改线宽重跑就行。

打包 dmg 用 `./package.sh`，文件名必须是 `NearbyPass-<版本号>.dmg`，App 内的自动更新靠这个名字找附件。

## 已知问题

- 手环的 BLE 广播常常不稳定，手机更可靠一些
- 安卓手机的广播名是随机串，且读不到 GATT 设备名，只能手动命名
- 用 iPhone 的话，手机息屏放兜里广播会变稀疏，解锁可能慢几秒
- 只在 macOS 27 上测过
- 自动更新不校验 Apple 公证，只看 bundle id 和我自己的证书指纹
- 界面用 SwiftUI 写，最低 macOS 14
